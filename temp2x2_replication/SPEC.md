# Prompt x temperature replication: prespecified design and analysis

**Status:** approved by Chris and Rahul on 12 Nov 2026 and frozen as git tag `temp2x2-v1` before any real session was collected.
**Written:** 12 Nov 2026, in response to the ICLR 2027 reviews of submission 47839.

## Why

Two reviewers raised the same gap.

- Reviewer G3t6 (Q1): does the informed-framing effect on win rate survive as the headline effect "at temperatures where a mixed strategy is even representable, with session counts matched to the temperature 0 study"?
- Reviewer ADg6: "the temperature checks do not directly compare both prompting conditions."

The paper concedes this in Appendix F.3 and Appendix G: the July temperature checks ran the informed prompt only, four sessions per cell. This study crosses both prompts with temperature 0 and 1 at seven sessions per cell, the main study's count.

## Design

**196 sessions: 7 models x 2 prompts x 2 temperatures x 7 sessions x 200 rounds = 39,200 rounds.**

All four cells are collected fresh, in one interleaved stream per model, so temperature is not confounded with collection date or checkpoint drift. Nothing from July is reused in the confirmatory analysis.

Each model runs 14 adjacent minimalist/informed pairs: 7 at temperature 0 and 7 at temperature 1.

- **Temperature order.** Pairs alternate temperature in an ABBA pattern (0 1 1 0 0 1 1 0 ... or its mirror). Three models start at temperature 0 and four at temperature 1, split within every developer.
- **Prompt order within pairs.** Within each temperature the seven pairs alternate which prompt runs first. Seven is odd, so a model has informed first in 3 or 4 of its 7 pairs. The split is identical at both temperatures within a model, so it cancels in the interaction, and it is flipped across models (four models 4/3, three models 3/4). Each model keeps its A/B assignment from the July counterbalanced replication. The sequences themselves differ: July's had eight pairs (A = I M M I M I I M), these have seven (A = I M M I I M M).
- **Position balance.** Mean serial position of the four cells differs by at most 0.43 of a session within any model (out of 28).
- **Seeds.** Master seed 20261112. Both sessions of a pair share one Proteus seed (master x 1000 + pair number, 98 seeds), as in July.

|---|---|---|
| Claude Opus 4.8 | B | 0 |
| Claude Sonnet 4.6 | B | 1 |

The schedule is generated by `make_config.py` with no randomness and stored in `run_config.json`.

**Held identical to the main study:** both system prompts (SHA-256 verified against the July logs), the history display, Proteus (Algorithm 2, commits before the model's choice), 200 rounds, top-p unset, 20,000-token cap with escalation, parser, 93-column logging. **The only manipulated settings are prompt and temperature.**

## Prespecified analysis (`analyze_temp2x2.py`)

The unit of analysis is the model (n = 7), as in the paper. For each model and temperature T, the framing effect D_T is the mean of its seven within-pair differences in win rate, informed minus minimalist.

- **Primary.** Framing effect at temperature 1: mean of D_1 across the seven models, paired t-test with t(6) interval, exact Wilcoxon signed-rank, and the count of models with a decline. This is the reviewer's question as asked.
- **Secondary 1.** Framing effect at temperature 0 (D_0), a second replication of the headline on current checkpoints.
- **Secondary 2.** Prompt x temperature interaction: D_1 minus D_0 per model, t(6) interval. Reported as an estimate with its interval. With n = 7 a nonsignificant interaction does not show the effect is the same size at both temperatures.
- **Secondary 3.** Signatures per cell: runs z, |P(TRIANGLE) - .5|, alternation rate, with the informed-minus-minimal contrast at each temperature. This tests whether over-alternation under the informed prompt is specific to greedy decoding.
- **Secondary 4.** Within-pair order check at each temperature.

**Interpretation fixed in advance.** The claim "the framing effect is not an artifact of temperature-0 decoding" is supported if the primary estimate is negative with an interval excluding zero. If the interval includes zero, the paper reports that and restricts the headline claim to temperature 0. Either way the abstract and Section 4.1 report the temperature-1 numbers next to the temperature-0 numbers.

**Data rules.**
- Only complete 200-round sessions enter. An interrupted session is rerun by the resume guard under the same index and seed; partial files are ignored.
- A session aborted for truncation is rerun the same way.
- Rounds where the choice did not come from the model (parse or API fallback) are counted and reported. The primary analysis keeps those sessions; a sensitivity analysis drops every pair containing one.
- If a model becomes unavailable mid-run, its completed pairs are reported descriptively and the confirmatory tests use the models with all 28 sessions.

## What this does not address

Other reviewer requests are outside this study: a second adaptive opponent or a simple alternation detector (G3t6 Q3, ADg6 Q2), a richer game (G3t6 Q2, 7YWi), a prompt that explains the opponent but keeps the prediction objective (ADg6 Q1), and the novelty comparison with Wang et al., ICML 2026 (7YWi).
